RustDesk 客户端 —— 使用说明
================================================================

这个文件夹里是已经配好自建服务器的 RustDesk 客户端，直接运行就能用，
不需要你自己去填服务器地址。

【一、怎么用（三步）】

  1. 把整个文件夹（或收到的压缩包）解压到任意位置，比如桌面。
     如果是压缩包发过来的，解压前先右键压缩包 → 属性 → 勾选
     「解除锁定」，再解压，否则 Windows 会拦截里面的脚本。

  2. 双击  「1-一键配置并启动.bat」
     - 它会自动把服务器设置写进客户端，然后启动 RustDesk。
     - 如果杀毒软件或 Windows 弹窗询问是否允许，选择「允许/仍要运行」。

  3. RustDesk 窗口打开后，界面上会显示本机的「ID」和「临时密码」。
     把 ID 和密码发给对方，就能被远程控制了。

【二、服务器信息（已预置，无需手填）】

  ID 服务器   : 见 服务器设置.ini
  中继服务器  : 见 服务器设置.ini
  Key(公钥)   : 见 服务器设置.ini

  注意：Key 必须填写，这是自建服务器的加密密钥。
        不填 Key 会一直显示「正在连接」，永远上不了线。

【三、以后要改服务器设置怎么办】

  双击  「2-修改服务器设置.bat」
  会弹出一个小窗口，里面就是上面那三项，改完点「确定」即可。
  客户端会自动重启使设置生效。

  也可以直接改 服务器设置.ini 这个文本文件（用记事本打开），
  改完保存，再双击「1-一键配置并启动.bat」。
  两种方式效果一样，改哪个都行。

【四、文件夹里都是什么】

  rustdesk.exe            官方 RustDesk 客户端
  1-一键配置并启动.bat     按预设值配置好并启动客户端
  2-修改服务器设置.bat     打开设置窗口，改 ID 服务器/中继/Key
  set-server.ps1          上面两个 bat 实际调用的脚本（不要删）
  服务器设置.ini           预设的服务器信息，可用记事本改
  使用说明.txt             本文件

  配置实际写入位置：
    用户级（便携模式读这里）
    %APPDATA%\RustDesk\config\RustDesk2.toml
    服务级（装成系统服务后读这里，需管理员权限才能写）
    %ProgramData%\RustDesk\config\RustDesk2.toml
  每次写入前会自动备份一份 RustDesk2.toml.bak

  「一键配置」会同时写这两个位置（本机没装服务就只写用户级），
  写完会回读校验，三项设置对不上会直接报错，不会静默失败。

【五、常见问题】

  Q: 双击 bat 一闪而过 / 提示找不到 powershell？
  A: 说明系统策略禁止运行脚本。可以右键 bat → 以管理员身份运行再试；
     或者手动打开 RustDesk，点 ID 右边的菜单 → 网络 → 解锁设置，
     自己把上面三项填进去（效果完全一样）。

  Q: 一直显示「未就绪，请检查网络连接」？
  A: 优先检查服务端的安全组是否放行了 UDP 21116。
     这是最常见的坑：只放行 TCP 时端口扫描显示"通"，但客户端注册走的是 UDP，
     于是永远卡在「未就绪」。
     其次检查 Key 是否填错（要原样整串复制，包含结尾的 =）。

  Q: 想被别人远程控制（无人值守），怎么办？
  A: 在 RustDesk 主界面点「安装」，把 RustDesk 装成系统服务，
     这样锁屏/重启后也能连上。只用来控制别人则不需要安装。

      重要：装成服务后，服务读的是 %ProgramData% 下的配置，
      而不是用户目录。所以装完服务后请右键「1-一键配置并启动.bat」
      →「以管理员身份运行」再配置一次，否则服务可能仍拿旧设置注册，
      表现为界面里填了服务器地址却一直上不了线。

  Q: Windows 提示「已保护你的电脑」/ SmartScreen？
  A: RustDesk 官方客户端未做商业代码签名，点「更多信息」→「仍要运行」即可。

  Q: 需要联网吗？
  A: 需要。你的客户端要能访问服务器地址才能上线。
